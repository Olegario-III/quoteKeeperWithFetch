# Random Quote Machine 💬

A simple and elegant **Random Quote Machine** that displays inspirational quotes with a new background color every time.

Built as a FreeCodeCamp front-end project.

## ✨ Features

- Fetches random quotes from a public API (GitHub Gist)
- Displays quote text and author
- Changes the background to a random dark color on every new quote
- One-click **Tweet** button to share the quote
- Responsive design using Bootstrap
- Includes FreeCodeCamp test suite
